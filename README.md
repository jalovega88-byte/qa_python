# Тестирование BooksCollector

## Описание проекта

Проект содержит класс `BooksCollector`, который позволяет добавлять книги, устанавливать им жанры, получать книги определённого жанра и работать со списком избранных книг.

Для проверки работы класса написаны юнит-тесты с использованием библиотеки `pytest`.

## Реализованные тесты

В проекте реализовано 10 тестовых методов.

### 1. Добавление книг

Проверяется добавление двух книг в словарь `books_genre`.

Проверяемый метод:
- `add_new_book`

### 2. Добавление книги без жанра

Проверяется, что после добавления новой книги её жанр по умолчанию является пустой строкой.

Проверяемые методы:
- `add_new_book`
- `get_book_genre`

### 3. Установка жанра книги

Проверяется, что книге можно установить жанр из списка доступных жанров.

Проверяемые методы:
- `add_new_book`
- `set_book_genre`
- `get_book_genre`

### 4. Получение книг определённого жанра

Проверяется получение списка книг с указанным жанром.

Тест параметризован и проверяет несколько жанров.

Проверяемый метод:
- `get_books_with_specific_genre`

### 5. Получение словаря книг

Проверяется, что метод возвращает текущий словарь `books_genre`.

Проверяемый метод:
- `get_books_genre`

### 6. Получение книг для детей

Проверяется, что книги с возрастным рейтингом не попадают в список книг для детей, а книги без возрастного ограничения попадают.

Проверяемый метод:
- `get_books_for_children`

### 7. Добавление книги в избранное

Проверяется добавление существующей книги в список избранного.

Проверяемый метод:
- `add_book_in_favorites`

### 8. Повторное добавление книги в избранное

Проверяется, что одну и ту же книгу нельзя добавить в избранное дважды.

Проверяемый метод:
- `add_book_in_favorites`

### 9. Удаление книги из избранного

Проверяется удаление книги из списка избранного.

Тест параметризован и проверяет удаление нескольких книг.

Проверяемый метод:
- `delete_book_from_favorites`

### 10. Получение списка избранных книг

Проверяется, что метод возвращает актуальный список избранных книг.

Проверяемый метод:
- `get_list_of_favorites_books`

## Параметризация

В тестах используется `pytest.mark.parametrize`.

Параметризация применена для:

- проверки книг с разными жанрами;
- проверки удаления разных книг из избранного.

Это позволяет не дублировать одинаковый код тестов.
