# Тестирование BooksCollector

## Описание проекта

В проекте реализованы юнит-тесты для класса `BooksCollector` с использованием библиотеки `pytest`.

Тесты проверяют добавление книг, работу с жанрами, получение книг для детей и работу со списком избранных книг.

Для создания объекта `BooksCollector` используется фикстура `collector`, которая находится в файле `conftest.py`.

## Реализованные тесты

### 1. Добавление книги с граничными валидными значениями

Проверяется добавление книги с названием длиной:

* 1 символ;
* 40 символов.

Используется параметризация.

Проверяемый метод:

* `add_new_book`

### 2. Добавление книги с невалидной длиной названия

Проверяется, что книга не добавляется, если название:

* пустое;
* содержит 41 символ.

Используется параметризация.

Проверяемый метод:

* `add_new_book`

### 3. Установка жанра книги

Проверяется, что существующей книге можно установить жанр из списка доступных жанров.

Проверяемый метод:

* `set_book_genre`

### 4. Получение жанра книги

Отдельно проверяется метод, который возвращает жанр книги по её названию.

Проверяемый метод:

* `get_book_genre`

### 5. Получение книг с определённым жанром

Проверяется получение списка книг, которым установлен указанный жанр.

Проверяемый метод:

* `get_books_with_specific_genre`

### 6. Получение словаря книг

Проверяется, что метод возвращает текущий словарь `books_genre`.

Проверяемый метод:

* `get_books_genre`

### 7. Получение книг для детей

Проверяется, что книги с возрастным рейтингом не попадают в список книг, подходящих детям.

Проверяемый метод:

* `get_books_for_children`

### 8. Добавление книги в избранное

Проверяется добавление существующей книги в список избранного.

Проверяемый метод:

* `add_book_in_favorites`

### 9. Удаление книги из избранного

Проверяется удаление книги из списка избранных книг.

Проверяемый метод:

* `delete_book_from_favorites`

### 10. Получение списка избранных книг

Проверяется, что метод возвращает актуальный список избранных книг.

Проверяемый метод:

* `get_list_of_favorites_books`

## Параметризация

Параметризация `pytest.mark.parametrize` используется для проверки граничных значений длины названия книги.

Проверяются:

* валидные значения: 1 и 40 символов;
* невалидные значения: 0 и 41 символ.

## Фикстура

В файле `conftest.py` создана фикстура `collector`, которая возвращает новый экземпляр `BooksCollector` для каждого теста.

Это позволяет не дублировать создание объекта в каждом тесте и сохраняет независимость тестов.

## Запуск тестов

Для запуска тестов используется команда:

```bash
python -m pytest -v tests.py
```

Все реализованные тесты проходят успешно.
